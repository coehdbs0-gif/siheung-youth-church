# 시흥제일 청소년교회 웹사이트 (Siheung Jeil Youth Church)

시흥제일교회 청소년교회(중·고등부)를 위한 Next.js 모던 웹사이트입니다.

## 📌 주요 기능

1. **메인 화면 (`/`)**
   - 슬로건 및 비전 히어로 배너
   - 담당 교역자(김은총 전도사) 프로필 및 따뜻한 메시지 카드
   - 이번 주 예배 요약 (시간, 장소, 설교 본문 및 찬양 맛보기)
   - 최신 유튜브 설교 영상 플레이어 및 공식 인스타그램 연동 링크
   - 네이버 지도 연동 찾아오는 길 안내 (원클릭 길찾기 및 주소 복사)

2. **예배 & 말씀 (`/worship`)**
   - **예배위원 탭**: 인도자, 대표기도, 사회자, 찬양팀, 예배 담당 반 테이블 (*방송팀 제외 명세 완벽 준수)
   - **찬양 콘티 탭**: 주차별 찬양 순서 및 유튜브 영상 감상 링크
   - **설교 요약 탭**: 성경 본문, 핵심 요약글 및 설교 영상 플레이어

3. **통합 달력 (`/calendar`)**
   - 월별 캘린더 (교회 행사 vs 학교 학사일정/방학 구분 필터)
   - **월별 학생 생일자 축하**: 교회학교 안전 원칙에 따른 성함 마스킹 적용 (`김*우`, `이*진`)

4. **소통 게시판 (`/board`)**
   - **공지사항**: 카드뉴스 및 일반 공지 목록/상세 팝업
   - **기도제목 & 고민상담**: 학생 프라이버시 보호를 위한 4자리 비밀번호 기반 비밀글 등록 및 열람 기능

5. **교사 전용 (`/teachers`)**
   - 비밀번호 간이 인증 (기본 비밀번호: `1234`)
   - 구글 스프레드시트 온라인 출석부 원클릭 이동 버튼

---

## 🛠️ 기술 스택
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Deep Green & Navy Blue 테마)
- **Icons**: Lucide React
- **Deployment**: Vercel 지원 최적화

---

## 🚀 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 시작
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속합니다.

## 🚢 빌드 및 배포

```bash
# 프로덕션 빌드 검증
npm run build

# 배포 실행
npm run start
```
- GitHub 저장소 연결 후 [Vercel](https://vercel.com)에 Import하면 원클릭으로 무료 배포가 완료됩니다.
